## Objective
Draft the compatibility inventory required by spec §7.2 — the enumerated coverage baseline
that certification is judged against (its absence is exactly the "vacuously green suite"
Codex flagged BLOCKING). Deliver `spikes/w07-compat-inventory.md`; it gets frozen and
co-signed at W0 exit.

## Out of scope

task builds the UNIVERSE of items, each starting UNKNOWN. No source changes.

## Binding references
- spec §7.2 (the six mandatory enumeration axes), §7.3 (what certification checks per item
  — shape items so those checks attach), §4c (entry-point axis feeds/uses the same list as
  task 06 — coordinate via shared format below, not duplicated content).

## Context & decisions
Enumerate, with repo evidence (file:line or command registration site):
1. **Player entry points**: every command (core + FAWE-added, from PlatformCommandManager
   registrations + command classes), brush types, wand interactions, CUI channels.
2. **Public API entry points**: coarse-grained here (classes/areas) — task 06 owns the
   per-method table; reference its item IDs rather than re-listing.
3. **Adapter-owned state classes**: from `spikes/recon-adapters-nms.md` §6 table — each
   danger-zone row becomes inventory items (sections, tiles, entities, POI, light, tickets,
   packets, physics, worlds-map).
4. **Persistence surfaces**: history (FaweStreamChangeSet v1/v2, RollbackDatabase),
   clipboards (DiskOptimizedClipboard v1/v2), schematics (formats), config files, session
   storage.
5. **Lifecycle transitions**: boot/detection, world load/unload, chunk unload mid-edit,
   player quit mid-edit, plugin disable mid-edit, server shutdown, region ownership
   migration mid-edit.
6. **Degradation candidates**: seeded from spec §5 hard cases.
Format: one table per axis — `ID | item | evidence anchor | certification hook (which §7.3
check applies) | status=UNKNOWN`. Stable IDs (`INV-CMD-001`...) — tasks will map to them.

## Escape hatch
If an axis can't be enumerated exhaustively from static reading (e.g. dynamically
registered commands), enumerate the registration MECHANISM as an item and flag it.

## Acceptance criteria
`spikes/w07-compat-inventory.md` with all six axes, stable IDs, evidence anchors, zero
disposition claims. Count summary at top.
